# קולנוע DNA – מערכת ניתוח והמלצות קולנועית מבוססת מבע ותוכן

**קולנוע DNA** היא מערכת ניתוח, סינון וגילוי סרטים בצד-לקוח (Client-Side Web Application), הממפה סרטים לפי טביעת האצבע הקולנועית, הפסיכולוגית והאסתטית שלהם. במקום להסתמך על תגיות ז'אנר שטחיות, המערכת מנתחת כל סרט על פני 12 צירים דו-קוטביים המייצגים את המבע הקולנועי, הטמפרטורה הרגשית ומסנני הסף של היצירה.

---

## 1. ארכיטקטורה ומפרט טכני (Tech Stack)

המערכת בנויה כולה בארכיטקטורת **Static Client-Side**, המאפשרת ביצועים מיידיים (חישוב וסינון בפחות מ-2 מילי-שניות) ללא צורך בשרת Backend פעיל בזמן ריצה:

* **Frontend Framework:** React (Vite).


* **עיצוב וממשק (UI/UX):** Tailwind CSS בעיצוב כהה (Dark Mode), תמיכה מלאה ב-RTL/LTR, סליידרים דו-כיווניים באמצעות `rc-slider`, ואייקונים מספריית `lucide-react`.
* **מנוע מתמטי (`src/engine.js`):** מנוע חישוב וקטורי ב-JavaScript טהור המבצע נירמול סטטיסטי (StandardScaler), חישוב מרחקים אוקלידיים משוקללים, ותרגום לאחוזי התאמה בזמן אמת.


* **שכבת נתונים (`public/final_classified_db.json`):** מאגר JSON סטטי המכיל מעל 1,050 סרטים מסווגים, כולל מטא-דאטה, מזהי IMDb, קישורי ויקיפדיה, נתוני זכיות ומועמדויות לאוסקר, ונתיבים לפוסטרים מקומיים (`public/posters/`).

## 3. המודל המתמטי ואלגוריתם הדמיון

תהליך העיבוד והחישוב ב-`engine.js` מתבצע בארבעה שלבים מרכזיים:

1. **נירמול סטטיסטי (Z-Score Standardization):**
בעת טעינת המאגר (`processRawMovies`), המערכת מחשבת עבור כל אחד מ-12 המאפיינים את הממוצע ($\mu_j$) וסטיית התקן ($\sigma_j$) על פני כלל הסרטים במאגר. הציון הגולמי של כל סרט מתורגם לציון תקן כדי למנוע הטיה של צירים בעלי סולמות או התפלגויות שונות:



$$z_{i,j} = \frac{x_{i,j} - \mu_j}{\sigma_j}$$


2. **חישוב מרחק אוקלידי משוקלל (Weighted Euclidean Distance):**
כאשר נבחר סרט מטרה $A$, המערכת מחשבת את המרחק בינו לבין כל סרט אחר $B$ במאגר תוך הכפלת הפרשי ציוני התקן במשקל הציר ($w_j$):



$$d(A, B) = \sqrt{\sum_{j=1}^{12} w_j \cdot \left(z_{A,j} - z_{B,j}\right)^2}$$


3. **כיול דינמי והמרה לאחוזי התאמה:**
כדי ליצור סולם אחוזים עקבי והגיוני עבור כל סרט, המערכת ממיינת את כל המרחקים מסרט המטרה ושולפת את **האחוזון ה-40 (`scaleFactor`)** כעוגן נרמול. ציון הדמיון מחושב באמצעות פונקציית דעיכה מעריכית:



$$\text{Similarity} = 100 \cdot \exp\left(-0.45 \cdot \left(\frac{d(A, B)}{\text{scaleFactor}}\right)^{1.3}\right)$$


4. **בונוס חתימת במאי:**
אם לסרט המועמד יש אותו במאי כמו לסרט המטרה, המערכת מוסיפה בונוס של **+6.0%** לציון ההתאמה (מוגבל לתקרה מקסימלית של **96.0%**).

## 4. שימושים ויכולות קיימות במערכת

* **מציאת סרטים דומים לפי DNA:** לחיצה על כל סרט בגריד או דרך תיבת החיפוש מציגה מיידית את הסרטים הקרובים אליו ביותר מבחינה סגנונית ותמטית, ממוינים לפי אחוז התאמה (ללא תלות בז'אנר רשמי).


* **סינון רב-ממדי באמצעות סליידרים (Range Sliders):** אפשרות להגדיר טווחי מינימום ומקסימום מדויקים על כל אחד מ-12 הצירים במקביל (למשל: מציאת סרטים עם קאמריות בין 8 ל-10, עומק פסיכולוגי גבוה, ורמת אלימות 1). הסינון פועל גם על המאגר הכללי וגם בתוך תוצאות הדמיון של סרט נבחר.


* **כיול משקולות אישי (מודאל גלגל שיניים):** שליטה ידנית בזמן אמת על משקלי האלגוריתם – המשתמש יכול להגביר חשיבות של ציר מסוים (עד `×2.5`) או לכבות לחלוטין צירים שאינם רלוונטיים עבורו (`×0`), והדירוגים מתעדכנים מיידית.
* **חיפוש חכם ומהיר:** שדה חיפוש עם השלמה אוטומטית המאתר סרטים לפי שם בעברית, שם באנגלית או שם הבמאי.


* **כרטיסיית ניתוח סרט מפורטת (Movie DNA Profile):**
* פירוט מלא של ציוני הסרט בכל 12 המדדים באמצעות מדי התקדמות גרפיים.


* תקציר עלילה, שנת יציאה ושם הבמאי.


* חיווי ויזואלי לזכיות באוסקר (גביע זהב) ולמועמדויות לאוסקר (גביע כסף).


* קישור ישיר לערך הסרט בוויקיפדיה (`W`).


* אינטגרציה ישירה ל-**Letterboxd** (דרך `imdb_id`) המאפשרת מעבר מהיר לעמוד הסרט להוספה ל-Watchlist או דירוג.

## 6. הרצה מקומית ובנייה ל-Production

התקנת תלויות:

```bash
npm install

```

```bash
npm run dev
```
